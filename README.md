# Omkar Dhanave — Full Stack Web Developer Portfolio

A personal portfolio website for **Omkar Dhanave**, engineered with Next.js 14 (App Router), React 18, TypeScript, Tailwind CSS, and Framer Motion. Built with an editorial dark-first aesthetic inspired by Linear, Apple, and Vercel.

---

## ⚡ Tech Architecture

- **Framework**: [Next.js 14](https://nextjs.org/) (App Router, Server & Client Components)
- **UI & Styling**: [Tailwind CSS](https://tailwindcss.com/) with custom radial glows, matrix grids, and backdrop blurs
- **Motion & Micro-interactions**: [Framer Motion](https://www.framer.com/motion/) & [Canvas-Confetti](https://www.npmjs.com/package/canvas-confetti)
- **Icons**: [Lucide React](https://lucide.dev/)
- **Type Safety**: [TypeScript](https://www.typescriptlang.org/) (Strict Mode)
- **Deployment**: Zero-config [Vercel](https://vercel.com/) architecture

## 🛠️ Local Development

### Prerequisites
- Node.js `v18+` or `v20+`
- npm, pnpm, or yarn

### Installation
```bash
npm install
```

### Run Development Server
```bash
npm run dev
```
Open [http://localhost:3000](http://localhost:3000) in your browser.

### Build Production Bundle
```bash
npm run build
```

### Start Production Server
```bash
npm run start
```

---

## 🌐 Deploying to Vercel

1. Push this repository to GitHub.
2. Visit [Vercel Dashboard](https://vercel.com/new).
3. Import the repository.
4. Framework Preset will be automatically detected as **Next.js**.
5. Click **Deploy**. Zero additional configuration required.
